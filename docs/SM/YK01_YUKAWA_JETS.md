# YK-01 — Yukawa couplings of jet families: a vanishing theorem and the only tree-level way out (2026-10-02)

Module `mtft.matter.yukawa_jets`; tests `tests/test_yk01_yukawa_jets.py`; correction CC-36.

1. **Theorem (EXACT).** Under the Scherk–Schwarz twist the fermion zero modes of b = 0 blocks are exceptional jets, and any two jet classes have zero cup product
   (one cutoff: dbar chi ^ dbar chi = 0; equivalently, Cech classes of a two-set cover). The zero-mode Yukawa is a cup product, so every tree-level Yukawa between
   jet fermions vanishes — in every background since Matter-04.
2. **Classification (EXACT).** A superpotential Yukawa needs a Phi-type Higgs boson, which only an untwisted block has: N_L = N_R. Then (4,2,1) and (4bar,1,2) share
   the fermion twist eta N_4 N_L^-1: both jets (no Yukawas) or both untwisted. Tree-level Yukawas exist iff the quark–lepton group carries the Z/2 Wilson line eta.
3. **The resulting pattern (EXACT).** Quark/lepton fermions untwisted, squarks/sleptons jets; Higgs bosons untwisted, Higgsinos jets; gauge bosons untwisted,
   gauginos removed. SU(4), left–right parity, indices and slopes unchanged.
4. **Price (EXACT counts, three-cusp background).** Each matter entry gains the curve's copies: 25 vector-like pairs plus the net 3 (Hom(L->4) = (0,13,13),
   Hom(4->L) = (0,15,12)); (4,2,1) and (4bar,1,2) carry 424 Weyl each; 896 in all against 96 jet-only.
