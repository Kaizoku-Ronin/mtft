# RT-01 — the ratio-3 working background (2026-10-02)

Module `mtft.matter.ratio_three`; tests `tests/test_rt01_ratio_three.py`; command `python -m mtft matter ratio3`.
Background (FS-01): SU(4) kept, Higgs gamma-charges (1, 3), a = (-1, -1, 1, 0, 2), c = (0, 0, -1, 2, 0), exceptional area 2 A_E/3, 672 zero modes, nu^c uncharged.

1. **Leading order (STRUCTURAL).** The up and down Higgs entries share exceptional charge, point and cusp; only Delta differs: eps_d/eps_u = 3 exactly.
2. **First correction (ESTIMATE).** The Higgs width shrinks as 1/sqrt|Delta|, so the down-type plane wave is sampled over a smaller region:
   eps ~ K|Delta|phi'/sqrt(1 + 2u_Delta), u_Delta = |Delta|(eps_D/A_E)phi'. Where the eps magnitudes fit (r ~ 4,800-81,000) the ratio is 2.84-2.96 — 25 per cent above 2.30.
3. **Jet-sector neutrinos (STRUCTURAL).** In the one-orientation condensate vacuum nu^c cannot get a Majorana mass, N gets an unsuppressed Sigma^2 mass, and the
   nu^c–N pairing comes only through the suppressed D-term route. The light mass is then m_D^2 mu/M^2 ~ v^2/v_R: 27 MeV for the third family, independent of the
   suppression — a type-I seesaw at the Pati–Salam scale, ~10^9 too heavy. The jet sector does not rescue the neutrinos here.
