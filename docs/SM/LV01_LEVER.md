# LV-01 — the lever at the jet point (2026-10-07)

Module `mtft.matter.lever`; tests `tests/test_lv01_lever.py`.

Once parity is broken at P1, the first family reaches the rest by two routes: a **lever arm** u = Y13/Y23 (its grip on the *height* of the top's tail, against
the x-family's grip on the tail's *slope*) and a **local arm** v = Y12/m2 (its direct coupling to the x-family). The jet point is the fulcrum.

1. **Lever formulas (EXACT at leading order, ~10% checked).** V_us = |u - v|, V_ub/V_cb = |u|, m_d/m_s = |v(2u - v)|, so c = |u|/|u - v|: the long arm's share of the
   Cabibbo angle. Pure lever: c = 1, massless first family. Pure local arm: GST, and c = theta_12^u/V_us = 0.20 from the up sector.
2. **Correction.** FH-4 attached the texture-zero relation to rotation-type breaking; rotation is the pure lever (c = 1). CC-57 supersedes FH-4.
3. **What the data ask (NUMERICAL).** Down sector alone: opposite arms, u = 0.090, v = -0.135, m_d/m_s = 0.042 against 0.050.
4. **The CP test (ESTIMATE).** With the up sector's symmetric 1–2 angle and one phase, an exact fit with real arms predicts gamma = 17 or 141 deg against 65.7: real
   arms fail. A twist between the arms fits (-130 deg, lever share 0.26; or -89 deg, 0.46); the right-angle branch mirrors the measured near-right angle alpha.
5. **Where the test goes (STRUCTURAL).** c and gamma are set by the condensate's jets at the jet point; the window c in [0.35, 0.45] and gamma = 65.7 +- 3 deg are
   the pre-registered targets for that computation.
