# CO-01 — is there a conjugate condensate? (2026-10-05)

Module `mtft.matter.conjugate_orientation`; tests `tests/test_co01_conjugate_orientation.py`.

1. **Closed form (EXACT).** Rank-one Sigma with FI xi: V = (1/2)[(v^2 - xi)^2 + (5/8) v^4], so v^2 = (8/13) xi, residual U(1) D = -(5/13) xi, SU(2)_R D^3 = v^2/2. An aligned
   conjugate enters only through v^2 - vbar^2: V_D is exactly degenerate along that family, and any positive mass lifts it to vbar = 0. A conjugate condensate would need a
   negative mass no FI can supply (opposite charges); no other PS-scale condensate exists. One orientation is a theorem of the field content; VM-4 is superseded.
2. **Gauge loops (NUMERICAL).** m_R/m_L = (C_4 alpha_4 + C_2 alpha_R)/(C_4 alpha_4 + C_2 alpha_L) = 0.90 at the b–tau scale: ten per cent, not a factor five.
3. **What tells right from left (EXACT at tree level).** The condensate's block puts its other scalars in the residual D-terms: m^2 = (10/13) g^2 xi (e^c-type), (2/13) g^2 xi
   (coloured); the left-handed block feels no SU(2)_R D-term. Fermion pairs stay massless at tree level on both sides.
4. **The remaining mechanism (STRUCTURAL).** Radiative Dirac masses need the scalar partners in the loop; heavy partners suppress them. So the condensate lowers the
   right-handed fermion pairs' one-loop masses relative to the left-handed ones — TH-01's direction — by a factor set by M_PS over the Scherk–Schwarz scale.

Open: the one-loop Dirac masses with Scherk–Schwarz gauginos and split partners; the sign of the (4,2,1) scalars' residual U(1)_4 D-term.
