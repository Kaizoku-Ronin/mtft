# R2C-06 — the telescoping theorem: chirality and Higgs mass are one number on a curve (2026-09-19; EXACT)

## Theorem
A Yukawa from the 6D gauge vertex couples two family blocks (charges q1, q2) to a Higgs block with q_H = -(q1 + q2).  Charges are linear
in the line-bundle degrees, so d_H = -(d1 + d2).  Two left-handed families of index 3 force d_H = -6: by R2C-05 the Higgs block is tachyonic
at m^2 = -1/4 (curvature units) and carries index -6.  A flux-neutral Higgs would need d1 = -d2 — two 'families' of opposite chirality — never
a Standard-Model pair.  On a curve slope = degree, so the flux that makes the families chiral is the flux that makes the Higgs heavy.

## Checks
- M1: all four triangles (up, down, lepton, neutrino) close to zero; the forced Higgs hypercharges are exactly +1/2, -1/2, -1/2, +1/2 — the
  triangle identity FIXES the hypercharge assignment; the Higgs index -6 is the six extra doublet pairs recorded since SM-01.
- E7 -> E6 x U(1): blocks of charge 0, +-1 only; two 27_{+1} families need a Higgs of charge -2, absent.  M3 fails the Yukawa gate exactly:
  the E6 cubic 27^3 is not a gauge vertex, and the Wilson-line 78 connects Q to u^c only through X-boson components.

## Class-level no-go (EXACT)
With R2C-01 (no elementary-scalar Higgs for the arithmetic families), H-19 (a hyper-scalar Higgs in a charged block is massive at +|d|/24)
and R2C-05 (a vector Higgs in a charged block is tachyonic at -|d|/24): in the class "line-bundle fluxes on a curve, families as chiral zero
modes" there is NO leading-order electroweak hierarchy.  Gate `light_higgs` added to `research.pipeline` (FAIL, with the theorem as witness).

   or threefold FIBRED over X0(143) — the elliptic-surface / modular-family constructions already in the programme's orbit (Kuga–Sato over
