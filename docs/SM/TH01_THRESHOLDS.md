# TH-01 — can thresholds reconcile the scales? (2026-10-05)

Module `mtft.matter.thresholds`; tests `tests/test_th01_thresholds.py`.

1. **Left–right pairs cancel (EXACT).** R = N/D, N = alpha_Y^-1 - (5/3) alpha_3^-1, D = alpha_2^-1 - alpha_3^-1. A vector-like (4,2,1) pair adds (b_3, b_2, b_Y) = (4/3, 8/3, 8/9),
   a (4bar,1,2) pair (4/3, 0, 32/9); per log they shift (N, D) by (+4/3, -4/3)/(2 pi) and the opposite. Only a left–right asymmetry moves the matching; light right-handed
   pairs move it the right way.
2. **What it takes (NUMERICAL).** At the b-tau crossing N = 56.5, D = 15.4. R = 7/3 needs n l = 29.2; R = 1 needs 96.9. With 19 pairs: a factor 4.7 below the scale (7/3) or
   about 7 TeV (R = 1). Colour adjoints alone need Delta b_3 l = 195 — implausible.
3. **The design's pairs (EXACT).** Gamma-neutral two-point: one pair per block (impossible: l = 29). Matter blocks with gamma-charge c_L = c_R = c keep the bidoublet neutral
   and add 4c^2 pairs: 17 per block at c = 2, enough at a factor 5.6 if the right-handed ones are lighter.
4. **The shape (STRUCTURAL).** Torus towers enter through the DKL factor: Im tau |eta(tau)|^4 = 0.3527 for 143a1. The curve's towers bring the spectral invariant of X_0(143);
   A_X/A_E enters only through the difference of the towers' beta coefficients.
