# DP-01 — how strong the dressing must be, and the quark–lepton conflict (2026-10-05)

Module `mtft.matter.dressing_profiles`; tests `tests/test_dp01_dressing_profiles.py`.

1. **The light state stays massless (EXACT).** Gauge invariance pairs u^c with the conjugate leptoquark gaugino partner (Dirac KK mass M): the orthogonal combination stays massless
   with weight Z = M/sqrt(M^2 + m^2). No seesaw mass.
2. **Character selection (EXACT).** The charm's u^c (x-jet at P1) mixes only through the condensate's x-jet at P1; the top's through the condensate's value at P2.
3. **How strong (ESTIMATE).** z_u = 0.25 needs m_2/M = 3.9 (undressed top) to 4.9 (Z_3 = 0.8, m_3/M = 0.75): a strong x-jet at P1 and a gaugino tower near M_PS/2.
4. **Quarks and leptons conflict (EXACT given the structure).** With Pati–Salam-symmetric tails, (m_mu/m_tau)/(m_s/m_b) = z_e = 3.09. The same condensate and towers dress e^c like
   u^c, so z_e = z_u: 0.25 against 3.09, a factor 12. Taking z = 3.09 brings back a u^c/d^c tail ratio of 16, beyond flux. CD-4 becomes a caveat.

Open: whether SU(2)_R-breaking flux on the (B, A2) block can split the leptoquark and W_R towers so that they dress in opposite spatial patterns.
