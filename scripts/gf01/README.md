# GF-01 figures

Run from the repository root: `python scripts/gf01/gf01_dots.py`, `gf01_torus.py`, `gf01_twelve.py` write `docs/SM/figs/gf01_*.png`.
Numbers in the figures (couplings at m_Z, systole traces, loop lengths) are the ones `mtft.matter.forces` computes; the scripts recompute them
independently from the same inputs (PS-01's m_Z values) so the figures are a check, not a copy.
