# Counting correction

Before any atlas output or simulated flows were produced, the independent permutation enumeration caught a counting error in the plan: S4 has **5**, not 7, cycle partitions. S6 has 11, so the joint atlas contains **55**, not 77, types. The code assertion and output count are corrected. The original plan is retained with its original hash. Prime range, all-category enumeration, perturbations, seeds, measurements, and stopping criteria are unchanged. This correction does not select categories based on observations.
