# Local audit corrections to MTFT 0.26.0

This is a local audit variant dated 7 September 2026, not a newly published MTFT release. The upstream package version remains 0.26.0. The original uploaded release is preserved separately.

## SM-AUDIT-01 — Higgs quartic convention

The public `HIGGS.lambda_quartic` previously returned `(gamma / Omega)**2 / 2`. With the package's `m_H = v * gamma / (2*Omega)`, the canonical potential `V = -mu² H†H + lambda (H†H)²` requires `lambda = m_H²/(2v²) = (gamma/Omega)²/8`. The public value is corrected from 0.5179175466708401 to 0.12947938666771003. This agrees with `HosotaniMTFT.higgs_self_coupling()` at the shared default VEV. The old value remains under `HIGGS.lambda_quartic_RETIRED_SM_AUDIT_01`.

This change resolves the factor-four inconsistency. It does not resolve the separately recorded local/global VEV behavior or the distinct W/Z ratio formulae.

## SM-AUDIT-02 — Random SU(N) initialization

The QR initializer divided one row by the Nth root of the determinant. A factor applied to only one row multiplies the determinant by that factor, so the correction must use the entire determinant. `random_su_n` now divides the first row by `det(Q)`. The QR draw and random-number sequence are preserved in a shared helper. Historical invalid special-unitary draws remain reproducible through `random_su_n_RETIRED_SM_AUDIT_02`.

The corrected sampler is used automatically by `LatticeConfig.hot_start`. Previous hot-start trajectories generated by the defective sampler require rerunning before they can be treated as SU(N) simulations. This note does not certify the distribution through statistical tests or establish any lattice continuum result.

## Validation scope

Ten targeted pytest cases passed: six in `tests/test_sm_audit_corrections.py` and four existing Higgs-sector cases. Additional companion experiments checked 48 draws across N=2,3,5 and invariance of both implemented action terms under a local SU(3) transformation on one periodic 2^4 lattice. The full package test suite was not run.

Audit identifiers are retained from the companion Standard Model assessment; no new numbered CC entry is assigned here.
