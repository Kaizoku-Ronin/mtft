# Matter-03 Higgs lab

Open `MTFT_Matter03_Higgs_Lab.html` in a local browser. It is self-contained, responsive, and makes no network requests. Optional primary-source anchors are ordinary navigation links.

The lab separates four objects:

1. A conditional classical no-go for one directed Higgs and an existence theorem for the specified paired branch.
2. The charged degree-one deformation-complex count after pairing.
3. An INPUT finite electroweak quartic, which illustrates scale freedom but is not a computed B3 metric or potential.
4. An INPUT positive diagonal normalization example using the known rank-three residue minor. It is not a selected three-family sector or particle-mass prediction.

The mode panel is a fixed nonzero paired-background comparison, independent of the single/paired selector in panel 1. Its JSON evidence contains the independently reviewed exact Matter-03 charged-complex certificate: the six block ranks (2,2,5,3,17,12) total 41, so 279 − 1 − 41 = 237 charged degree-one classes remain per Q sign. This count uses the specified down canonical order3 and up order2 representatives. For any nonzero aligned pair, the six rectangular block capacities total 118 and give the robust lower bound 160. The fallback reviewed-data slot can show bounds only; the upper count bound 275 additionally uses the archived down-Higgs rank-three minor.

They do not test actual browser rendering, touch input, screen-reader behavior, or visual layout. Canvas has a descriptive accessible label and fallback text; core conclusions are also present as text and tables. No browser layout test has been performed in this workspace.

The accompanying study contains the precise classical parent, geometry, proofs and archived basis hashes. No Standard Model false-vacuum decay calculation is encoded.
